## Project updates

**Midtown Radio** has an app! It has light and dark modes, and you can listen to the station live. Next the team will pull on-demand shows from the station's API and hook into the phone's built-in media controls.

**Connected KW** is working on the profile form, a limit on how many tags a profile can have, and login. Next are categories and finishing the profile form.

**PECH** has lots of data and little capacity to analyze it. A data analyst there is already setting up a SQL database, so the question is how we can work alongside them. Possible next steps are getting a database schema and another brainstorm about internal communications.
